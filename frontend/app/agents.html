For agents

HTTP / JSON

The web page is free during the beta. Agents calling the API directly pay per report in USDG over x402 on Robinhood Chain — 0.02 for a token, curve or bond report, 0.05 for a pre-launch review. The wire contract is documented in agents.md.

POST /api/agents/report
content-type: application/json

{"kind":"token","token":"0x…"}
{"kind":"prelaunch","token":"0x…","lockAmount":5000000,"lockDays":180,"steps":6,"initialUnlockPct":10,"revocable":false}
{"kind":"curve","address":"0x…"}
{"kind":"bond","symbol":"OAKEN"}

Direct API base: https://agents.oaken.one. The free web proxy is https://oaken.one/api/agents.

Reports are stored and can be read back at /api/agents/report/<id> without paying again.

What this checks — and what it does not

The reports read runtime code, common ERC-20 selectors, the EIP-1967 implementation slot, OAKEN's lock adapters v1–v4, the vault schedule behind each lock, the Pons factory and curve, an OAKEN Curve v5 launch (supply, sellable allocation, tracked reserves, fees and graduation state), and the OAKEN bond vault, NAV oracle and staking pool. They do not read source code, holder distribution, off-chain social claims, or a third-party audit. A selector in bytecode is not a live function; an empty owner slot is not proof of renouncement; a curve price is not a promise of liquidity. The pre-launch plan is the one input that is not on-chain, and the report says so.

No LLM writes the numbers. An optional AI narrative may rephrase the fact sheet; it is dropped if it contains a number that is not already in the report, or if it gives advice. Direct API reports settle per report in USDG over x402 on Robinhood Chain; this web page is free during the beta and rate-limited. The report is stored so its URL stays stable.
