What this counts. The index is our own record of locks created through OAKEN; a lock that was created directly against the contract and never indexed will not appear. “Upcoming” is the next 30 days from the first indexed page per chain, not a full event scan. Amounts are token units, not dollars. Positions (Uniswap V3/V4 NFTs) are on Locks, not in this token table.

If the index cannot be read, this page keeps the last successful numbers and says how old they are; it never replaces them with zero. If only some chains answer, the totals stay blank, the missing chains say they did not answer, and the rest of the table still renders.
