Ownerless by design

Locks and positions have no owner, no pause, no upgrade and no rescue. The creator of a lock has one power: revoke its own lock, and only if the lock declared itself revocable at creation.

  • LockVault / PositionLock: no admin key, no proxy.
  • TokenFactory: fixed supply; no mint, pause or owner after deployment.
  • MultiSender: no storage between calls.
  • Airdrop / Presale / Launcher: product-specific creator powers, no upgrade key.

Admin is a different product

Bonds are not ownerless. They have a 2-of-3 Safe, a Timelock and a NAV keeper. Reading a bond as if it were a lock is a user-interface mistake; this page keeps the boundary explicit.

  • Safe: 0x5E8C4c241a29ff7E60c648f378A4AA70053Ee92e · 2-of-3.
  • Timelock delay at handoff: 86,400 seconds (24h).
  • Changing that number is a governance action through the Safe, not a promise made by this page.
  • Locks: no admin. Bonds: admin, keeper and oracle risk.

What the tests actually assert

Locks

Credited amount equals the balance delta (fee-on-transfer); vesting is monotone and bounded; claims pay only vested-minus-claimed to the beneficiary; revoke splits the amount exactly; a shrink edit cannot go below claimed; staircases never outrun the continuous curve.

Positions

One escrow per position; release is time-gated and pays only the stored beneficiary; reclaim is creator-only, revocable-only, and impossible after release; pushed-in NFTs without a lock record are refused.

Tools

Factory fixed supply, multisender batch atomicity, Merkle double-claim prevention and sweep deadlines, presale cap/refund accounting, and router liquidity shares.

Not covered by a proof

Rebasing tokens are not modelled; blacklists/hooks can block a claim; no formal verification has been performed. The invariant suite is evidence, not a proof.

For a vulnerability report, include the chain/address, function, a minimal reproduction and whether funds are at risk. Do not post exploit details publicly before a fix is live. There is no paid bounty program at this time; do not assume a payout or scope until an official program page exists.

What this page is not. It is not an audit report, a formal verification result, a bug bounty, or a guarantee. It is a statement of what has been tested and what has not. A matching bytecode proves the source matches the deployment; it does not prove the code is safe. Read the contracts and decide for yourself.
