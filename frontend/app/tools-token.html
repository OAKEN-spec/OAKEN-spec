A token with nothing hidden in it.

One transaction deploys a plain ERC-20 with the whole supply sent to you. There is no owner, no mint function, no pause and no burn — not "renounced", not "locked": the code has no such function, so there is nothing to renounce and nothing to unlock later.

If it fails — self-check

  • The supply is fixed at deployment. There is no mint, no burn and no owner — check the number before you sign.
  • Decimals are immutable. 18 is the common choice; a different value changes how every wallet displays the supply.
  • The whole supply goes to the deploying wallet. Locking a part of it is a separate step on the lock page.
  • The image is off-chain. For this factory the chain has no image field; the picture is stored on our image host and can disappear without affecting the token.
