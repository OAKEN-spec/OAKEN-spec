    How Solana locks work

    Tokens sit in an associated token account owned by a program-derived lock address. Only the program can move them, and only after the unlock time. Claim is permissionless: anyone can submit it, and the tokens always go to the beneficiary. There is no per-lock admin key and no pause on the lock itself — but the live program (Jupiter Lock) can be upgraded by its team; see below.
    OAKEN's own lock program is Co9ZnAVxX2siGThhjTpPgXPHYrCev1nrXFyGB1VcZcQW (source in the repository). It is deployed on Solana mainnet, upgrade authority none, and passed a 25-check E2E on a local validator. Jupiter Lock (LocpQgucEQHbqNABEYvBvwoxCPsSbG91A1QaQhQQqjn) remains a third-party option; Jupiter's program can be upgraded by its team. Neither product is audited by us.
